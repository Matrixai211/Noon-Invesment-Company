# Noon Investment Company

Corporate website for **Noon Investment Company**, a diversified holding and operating company.

## Brand

- Name: Noon Investment Company
- Mark: Arabic letter **ن** (Nun / “Noon”)
- Tagline: **Invest. Build. Trade. Grow.**
- Positioning: **Building Businesses. Empowering Generations.**
- Palette: deep navy, metallic gold, cream and white

## Run locally

This first release is dependency-free.

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

You can also open `index.html` directly in a browser.

## Deploy

The site is static and can be deployed to Vercel, GitHub Pages, Netlify, Cloudflare Pages, or any standard web host.

### Vercel

Import this repository into Vercel. No build command is required; serve the repository root as a static site.

## Important placeholders

The current contact email in `index.html` uses the reserved `.example` domain so no fake real-world contact details are presented. Replace it after Noon has an official domain and email address.
